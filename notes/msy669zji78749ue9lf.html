业务背景

HTML 作为 AI 时代原生内容格式，支持人直接编辑、agent 结构化读取、多渠道分发。

核心场景

优先级场景用户价值
P0作者用 HTML 发布内容一次生产，多渠道分发
P0人需要快速改错别字、调颜色、改标题原地编辑
P0agent 结构化理解内容后执行改写/总结/翻译保留语义标签，解析成本低

功能需求

原地编辑

HTML 在资料库中可直接点击编辑，光标可进入标题/段落，保留样式属性，所见即所得。

结构化解析

agent 读取 HTML 时保留标题层级、列表、表格等语义，输出结构化 JSON 或 Markdown。

格式转换

同一份 HTML 可按需转换为 PDF、epub、md，转换器可配置模板。

  2. 选 1 本已分片的橙皮书做试点：验证原地编辑、AI 建议、版本历史、导出全链路
  3. 建立 HTML→MD→PDF 的转换质量基线
