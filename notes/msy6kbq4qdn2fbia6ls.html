目标

在手机上可监控电脑端任务进度、中途介入调整指令，并按任务类型选择“本地电脑执行”或“云端执行”。

执行方案

远程监控层

推荐：SSH + tmux + 状态文件组合，成本最低、配置最快。

中途介入机制

指令队列文件 + 状态标记文件，双保险。agent 定时读取 pending_commands.txt，手机随时写入新指令。

执行位置选择

任务类型推荐执行位置原因
长耗时批量任务本地电脑利用闲置算力
需要 GUI/浏览器本地电脑远程桌面接管
轻量对话/推理云端电脑锁屏不影响
定时闲时任务本地电脑夜间自动跑，白天手机查看结果

实施步骤

  1. 确认电脑 SSH 可达，配置密钥免密登录
  2. 安装 tmux，建立常驻会话命名规范
  3. 在 agent 工作目录建立 control.flag + pending_commands.txt
  4. 配置 Telegram/飞书推送，绑定关键节点通知
  5. 测试：手机 SSH → attach tmux → 查看任务进度 → 写入暂停指令 → agent 响应

下一步行动建议

  1. 先核对基线：确认电脑 SSH 可达、tmux 可用、手机终端可连接
  2. 跑通最小闭环：手机 SSH → attach tmux → 查看进度 → 写入指令 → agent 响应
  3. 把「执行位置决策表」写入现有 scheduler 任务配置
