Goal Contract（标准模式）h2>

Goal: 把已有知识和产出沉淀为 agent 可读、可检索、可复用的资料库资产，形成闭环。

Intent: 让过去几年的内容、方法、对话都能被 agent 持续调用，越用越厚。

关键约束

  • 必须基于现有 remio/WorkBuddy/资料库能力，不新建独立系统
  • 知识复利激活规则必须可被 agent 自动执行，不能依赖人工记忆
  • 所有沉淀物必须标注来源和可复用场景

下一步行动建议

  1. 先跑“任务0”基线核对：确认现有资料库结构、agent 可读入口、已有笔记分布
  2. 用「我把10本橙皮书搬进了WorkBuddy！」作为第一个复利试点
  3. 建立知识复利迭代节奏：每周/每双周由 agent 自动盘点“新增沉淀物 + 激活次数 + 未激活资产”
